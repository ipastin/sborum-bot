# Сборум

## Возможности

- несколько мероприятий в одном Telegram-чате;
- два типа мероприятий:
  - `📅 Разовое`;
  - `🔁 Повторяющееся`;
- добавление через `/addevent`;
- просмотр и редактирование через `/events`;
- настройка даты, периодичности, времени публикации, длительности голосования, timezone и минимального кворума;
- приостановка и удаление мероприятий;
- тестовые голосования;
- автоматический пересчёт кворума;
- автоматическое закрытие голосований;
- точная дата и относительная формулировка в напоминании:
  - `сегодня`;
  - `завтра`;
  - `послезавтра`;
  - `через N дней`.

## Пример напоминания

```text
Напоминание о предстоящем мероприятии.
Мероприятие «Волейбол» состоится послезавтра: 18 июня 2026 г.
Минимальный кворум — 6 человек.
Пожалуйста, отметь актуальный вариант в голосовании ниже.
```

## Развёртывание

Бот работает на **Cloudflare Workers** (webhook + D1 + Cron Trigger). Подробный
рунбук — в [`docs/cloudflare-deploy.md`](docs/cloudflare-deploy.md).

Кратко:

```bash
npm install
npm run d1:migrate                              # применить схему к базе D1
npx wrangler secret put BOT_TOKEN               # токен от @BotFather
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET # длинная случайная строка
npm run deploy
node scripts/set-webhook.mjs <BOT_TOKEN> https://sborum-bot.<субдомен>.workers.dev/ <TELEGRAM_WEBHOOK_SECRET>
```

## Команды Telegram

| Команда | Назначение |
|---|---|
| `/events` | список мероприятий и настройки |
| `/addevent` | добавить мероприятие |
| `/schedule` | ближайшие активные мероприятия |
| `/status` | текущий кворум |
| `/publish` | тестовое голосование |
| `/closepoll` | закрыть последнее открытое голосование |
| `/cancel` | отменить пошаговый ввод |
| `/version` | версия бота |
| `/chatid` | ID чата и topic |
| `/whoami` | твой Telegram user ID |
| `/help` | краткая справка |
