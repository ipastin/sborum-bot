# Сборум

Telegram-бот для групп: публикует опрос перед разовым или повторяющимся мероприятием и показывает, набран ли кворум. Помогает организатору не собирать ответы вручную.

## Как это работает

1. Администратор группы или владелец бота создаёт мероприятие через `/addevent`: выбирает тип, дату, время публикации, длительность голосования, часовой пояс и нужное число ответов «✅ Буду».
2. Бот публикует напоминание и неанонимный опрос в том же чате или topic. Участники выбирают «✅ Буду», «❌ Не смогу» или «🤔 Пока не знаю».
3. `/status` показывает текущие ответы и остаток до кворума. По истечении заданного времени бот закрывает голосование.

В одном чате можно вести несколько мероприятий, приостанавливать их и менять настройки через `/events`. Разовое мероприятие перестаёт планироваться после своей даты.

> На текстовые вопросы мастера отвечай через Reply: бот запрашивает такой ответ с помощью ForceReply, поэтому отключать privacy mode не требуется. Для «Другой часовой пояс» выбери Reply вручную. Обычные сообщения без Reply доступны боту, если он администратор группы или privacy mode отключён. `/publish` создаёт настоящее тестовое голосование в чате.

Сообщение о смене кворума отправляется без гарантии доставки: при ошибке Telegram голоса сохраняются, но уведомление автоматически не повторяется. Актуальный кворум можно проверить через `/status`.

## Быстрая локальная проверка

Нужен Node.js 20 или новее. Этот путь проверяет исходный код и тесты без Telegram-токена, Cloudflare и живых голосований.

```bash
git clone https://github.com/ipastin/sborum-bot.git
cd sborum-bot
npm ci
npm run check
npm test
```

Для запуска самого бота нужны аккаунт Cloudflare, тестовый Telegram-бот от BotFather, D1 и webhook. Бот работает в Cloudflare Workers: Telegram отправляет обновления через webhook, D1 хранит мероприятия и голоса, Cron Trigger раз в минуту проверяет публикацию и закрытие опросов.

## Обновление и развёртывание

Проект уже работает на **Cloudflare Workers + D1**. Выбери свой сценарий в runbook:

- **[Обновление действующего Worker](docs/cloudflare-deploy.md#обновление-действующего-worker):** проверь Cloudflare account, имя Worker, существующую D1, миграции и секреты. Сохрани действующие `database_id`, `OWNER_USER_ID` и Telegram-бота, если они соответствуют проверенной production-конфигурации. При неизменных URL и webhook secret и уже правильных параметрах доставки переустанавливать webhook не требуется.
- **[Новая установка](docs/cloudflare-deploy.md#новая-установка):** начни с отдельного тестового бота и своей D1. В `wrangler.jsonc` уже указаны конкретные `database_id` и `OWNER_USER_ID` — замени их своими и сверь цель до удалённой миграции. Секреты не записывай в Git.
- **[Legacy: перенос с VPS](docs/cloudflare-deploy.md#legacy-перенос-с-vps):** историческая инструкция для отдельного случая. Она не нужна для текущего Cloudflare-обновления и не подтверждает наличие пригодного VPS для отката.

Скрипт `scripts/set-webhook.mjs` сохраняет очередь updates при установке и удалении webhook. Он принимает токен аргументом командной строки; учитывай историю shell и список процессов.

## Команды Telegram

| Команда | Что делает | Доступ |
|---|---|---|
| `/start`, `/help` | Краткая справка | Все |
| `/events` | Список мероприятий; администратору доступны настройки | Все |
| `/addevent` | Создать разовое или повторяющееся мероприятие | Администратор или владелец бота |
| `/schedule` | Ближайшие активные мероприятия | Все |
| `/status` | Статус открытых голосований и кворума | Все |
| `/publish` | Опубликовать тестовое голосование | Администратор или владелец бота |
| `/closepoll` | Закрыть последнее открытое голосование в чате | Администратор или владелец бота |
| `/cancel` | Отменить текущий пошаговый ввод | Все |
| `/version` | Версия бота | Все |
| `/chatid` | ID чата и topic | Все |
| `/whoami` | Твой Telegram user ID | Все |

Администратор здесь — администратор или создатель Telegram-группы; `OWNER_USER_ID` даёт права управления владельцу бота. Голоса в опросе неанонимные, иначе бот не смог бы считать участников кворума.
