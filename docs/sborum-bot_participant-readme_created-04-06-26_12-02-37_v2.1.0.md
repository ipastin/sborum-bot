# Сборум

**created:** 04-06-26, 12-02-37 UTC  
**updated:** 04-06-26, 12-02-37 UTC  
**version:** 2.1.0 — docs: add participant README

Сборум помогает понять, соберётся ли кворум на мероприятие.

## Как это работает

Перед мероприятием бот публикует голосование:

- `✅ Буду`
- `❌ Не смогу`
- `🤔 Пока не знаю`

Выбери актуальный вариант. Если планы изменились — просто измени голос.

Бот автоматически сообщит:

- когда кворум набран;
- если после изменения ответов кворум снова потерян;
- итог после закрытия голосования.

## Полезные команды

| Команда | Что показывает |
|---|---|
| `/schedule` | ближайшие мероприятия |
| `/status` | текущий статус кворума |
| `/events` | список мероприятий |
| `/help` | краткую справку |

## Почему голосование неанонимное

Это нужно, чтобы бот корректно пересчитывал кворум, если участник изменит ответ.
